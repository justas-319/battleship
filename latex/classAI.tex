\doxysubsection{Detailed Description}
Represents a computer-\/controlled player in a game of Battleship. 

Extends \doxylink{classPlayer}{Player} with:\+
\begin{DoxyItemize}
\item \doxylink{classAI_a9723db73558bd0e9e8757ae1c556bdd4}{setup\+Grid()} :\+ automatically places all ships on the \doxylink{classAI}{AI}\textquotesingle{}s own board using random-\/but-\/valid positions.
\item \doxylink{classAI_a2f51f6c43d2a59bc665a138a9a0a325d}{fire\+Shot()} :\+ automatically selects an un-\/fired target cell. The base implementation uses a random strategy; the game logic layer may call more sophisticated selection. 
\end{DoxyItemize}
