\doxysubsection{Detailed Description}
Abstract base class representing a player in a game of Battleship. 

Holds the player\textquotesingle{}s own board (where their ships reside) and a target grid (a local record of shots fired at the opponent\textquotesingle{}s board). Concrete subclasses must implement \doxylink{classPlayer_a1bad3a553a1f0147e46ca8d16a173eb4}{fire\+Shot()}, which differs between a \doxylink{classHuman}{Human} (user input) and an \doxylink{classAI}{AI} (automated selection).
